# GitHub Developer Discovery — Frontend

React 19 SaaS dashboard for discovering and managing GitHub developer prospects.

## Quick Start

```bash
npm install
npm run dev
```

Open **http://localhost:5173**. Ensure the backend is running at `http://localhost:3000`.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |

## Stack

React 19 · TypeScript · Vite · TailwindCSS · Zustand · TanStack Query · Framer Motion · Recharts
